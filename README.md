# Sales Data Cleaning & Analysis (Sample Project)

A realistic example of turning a messy sales export into trustworthy data and clear insights.

**Problem:** 4,240 raw rows with duplicates, mixed date formats, inconsistent spellings,
missing values, and impossible quantities/prices.

**Solution:** Cleaned with Python (pandas), every change logged, outliers handled by rules,
missing numbers rebuilt from the order's other fields. Result: 3,992 validated orders.

**Deliverables:** clean Excel workbook (live-formula KPIs, charts, cleaning log),
CSV files, and a short report with findings and recommendations.

> All data is synthetic. No real customer or business is described.
